# Idealista Scraper API – code examples

Examples for every Idealista endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/property.sh`](curl/property.sh) | `bash property.sh` |
| cURL (Bash) | [`curl/provinces.sh`](curl/provinces.sh) | `bash provinces.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
